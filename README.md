# 스마트 GIF 생성기 (Smart GIF Maker) - Android WebView App

[스마트 GIF 생성기 (https://daons730.github.io/8/)](https://daons730.github.io/8/) 웹 애플리케이션을 안드로이드 스마트폰에서 쾌적하게 사용할 수 있도록 제작된 **풀스크린(전체화면) 네이티브 웹뷰 안드로이드 앱** 프로젝트입니다.

로컬 환경에 **안드로이드 스튜디오(Android Studio)가 설치되어 있지 않아도**, GitHub 저장소에 코드를 올리면 **GitHub Actions 클라우드 빌드 시스템**이 자동으로 최신 APK(Debug / Release)를 생성하여 다운로드할 수 있도록 완벽하게 세팅되어 있습니다.

---

## 📱 사이트 각 탭당 기능 상세 분석

대상 웹사이트(`https://daons730.github.io/8/`)를 정밀 분석하여 파악된 각 탭 및 핵심 기능은 다음과 같습니다.

### 1. 상단 내비게이션
* **국립한국해양대학교(KMOU) 로고**: 클릭 시 대학교 공식 홈페이지로 새 창 이동.
* **타이틀(스마트 GIF 생성기)**: 편집 도중 클릭하면 언제든 첫 화면으로 즉시 복귀하는 홈 버튼 기능.
* **메인 탭 메뉴**: `GIF 만들기`와 `내가 만든 GIF 보관함` 2개 탭 전환.

---

### 2. 탭 1 : [GIF 만들기]
동영상 또는 여러 장의 사진을 소스로 삼아 고화질 움직이는 GIF를 제작하고, 프레임 단위로 상세 편집할 수 있는 핵심 작업 공간입니다.

#### (1) 동영상으로 GIF 만들기 (Video Mode)
* **파일 첨부/드래그**: [동영상 첨부] 버튼 또는 드롭존을 통해 비디오 파일 업로드.
* **지원 포맷**: `MP4`, `WEBM`, `MOV`, `OGG`.
* **변환 규격**:
  * 최대 프레임: 초당 **30 FPS**.
  * 최대 길이: 최대 **10초** 분량 자동 프레임 디코딩 추출.
* HTML5 비디오 디코더를 통해 영상의 프레임을 캔버스 데이터로 캡처하여 편집창으로 전달.

#### (2) 이미지로 GIF 만들기 (Image Mode)
* **파일 첨부/드래그**: [이미지 여러 장 첨부] 버튼을 통해 복수 이미지 동시 선택.
* **지원 포맷**: `JPG`, `PNG`, `WEBP`, `GIF` (기존 GIF 파일 첨부 시 내부 프레임 분해 지원).
* 선택한 순서대로 각 이미지가 하나의 프레임으로 정렬되어 프레임 시퀀스 구성.

#### (3) GIF 편집창 (Editor Screen)
미디어가 로드되면 진입하는 고도화된 프레임 에디터입니다.
* **상단 바**:
  * `[처음으로]`: 첫 화면으로 복귀.
  * `파일명 & 변환 상태`: 인코딩 진행 상황(진행률 Bar, %) 실시간 표시.
  * `[다운로드]`: 인코딩 완료 시 활성화되는 GIF 파일 저장 버튼.
* **중앙 캔버스 작업 공간**:
  * 선택된 프레임의 고해상도 프리뷰 및 터치/펜 드로잉 지원.
  * 사진/스티커 추가 시 크기 및 위치를 조절할 수 있는 반응형 박스 및 핸들 제공.
* **하단 타임라인 썸네일 스트립**:
  * 모든 프레임을 가로 스크롤로 나열하여 특정 장면 탐색.
  * `[이 프레임 삭제]`: 불필요하거나 흔들린 프레임만 개별 제거.
* **우측/측면 도구 모음**:
  1. **펜 도구**:
     * 5종 펜 타입: `연필`, `마커`, `붓`, `형광펜`, `지우개`.
     * 굵기 조절 슬라이더: 2 ~ 40px.
     * 10가지 기본 프리셋 컬러 팔레트 + 커스텀 컬러 피커 (`<input type="color">`).
     * `뒤로 가기(Undo)` / `앞으로 가기(Redo)` 지원.
  2. **재생 속도 조절 (동영상 모드)**:
     * 0.25배속 ~ 4.00배속(약 30 FPS 기준) 속도 조절 슬라이더.
     * 실시간 미니 애니메이션 루프 프리뷰 캔버스 제공.
  3. **프레임 지속시간 조절 (이미지 모드)**:
     * 프레임별 노출 시간(0.1초 ~ 3.0초) 설정 및 [모든 프레임에 적용] 원클릭 버튼.
  4. **이미지 삽입 도구**:
     * 로컬 이미지 추가 첨부.
     * [다음 프레임으로 추가] 또는 [선택한 프레임 위에 붙이기(스티커/합성)] 지원.

---

### 3. 탭 2 : [내가 만든 GIF 보관함]
* 편집창에서 다운로드하거나 첫 화면으로 돌아갔을 때 제작된 GIF가 웹 로컬 스토리지에 자동 저장/기록됨.
* 보관된 GIF를 반응형 카드 그리드로 시각화.
* 각 보관 아이템:
  * 완성된 애니메이션 썸네일 미리보기.
  * 생성 일자 및 파일 정보.
  * 다시 다운로드 버튼 및 개별 삭제 기능 제공.

## 🎨 앱 아이콘 디자인 컨셉 & 리소스

앱의 성격("스마트하고 역동적인 움직이는 GIF 제작기")을 시각적으로 상징하도록 **밝고 세련된 네온 그라데이션** 스타일로 제작되었습니다.

### 1. 디자인 모티브
* **배경**: 심우주 네이비/슬레이트 바탕 위 인디고(`4F46E5`) ~ 일렉트릭 퍼플(`7C3AED`) ~ 시안(`06B6D4`) & 네온 핑크(`EC4899`)의 빛 번짐 효과.
* **필름 프레임 카드**: 비디오와 이미지를 프레임 단위로 추출하는 기능을 상징하는 둥근 필름 카드와 상·하단 스프라켓 홀(Sprocket holes).
* **인피니티 루프 화살표**: GIF의 핵심인 무한 반복(Infinite Loop)과 역동적인 재생을 의미하는 네온 링.
* **볼드한 "GIF" 타이포그래피**: 중심부에 선명한 흰색 볼드 타이포와 소프트 그림자 배치.
* **스마트 스파클(✨)**: 상단에 반짝이는 옐로우 스타를 배치하여 '스마트(Smart)' 인공지능/자동화 생성기의 아이덴티티 강조.

### 2. 포함된 아이콘 규격
* **Android Adaptive Vector Icons**:
  * `ic_launcher_background.xml`: 벡터 그라데이션 배경.
  * `ic_launcher_foreground.xml`: 고해상도 벡터 필름 + 루프 + GIF 심볼.
  * `ic_launcher_monochrome.xml`: Android 13+ 테마 아이콘 완벽 지원.
* **고해상도 PNG 래스터 에셋** (정밀 안티앨리어싱 렌더링):
  * `mipmap-mdpi` (48x48)
  * `mipmap-hdpi` (72x72)
  * `mipmap-xhdpi` (96x96)
  * `mipmap-xxhdpi` (144x144)
  * `mipmap-xxxhdpi` (192x192)
  * `ic_launcher-web.png` (512x512, 스토어 등록용 원본)
  * 사각(Square) 및 원형(Round) 아이콘 전 밀도 대응.

## ⚙️ 안드로이드 앱 주요 기술 사양

1. **전체화면 몰입형 모드 (Immersive Fullscreen)**:
   * `WindowCompat.setDecorFitsSystemWindows(window, false)`
   * 상태바와 내비게이션바를 숨겨 캔버스 작업 공간을 화면 끝까지 100% 활용.
   * 필요 시 화면 가장자리를 쓸어올려 시스템 바를 일시 호출하는 트랜지언트 스와이프 모드 적용.
2. **하드웨어 가속 (`android:hardwareAccelerated="true"`)**:
   * HTML5 비디오 프레임 추출, 대형 캔버스 드로잉, WebAssembly/GIF 인코딩 시 버벅임 없는 최대 그래픽 성능 제공.
3. **네이티브 파일 탐색기 브릿지 (`WebChromeClient.onShowFileChooser`)**:
   * 웹뷰의 파일 첨부 버튼(`attachBtn`, `imageAttachBtn`, `imageBtn`) 클릭 시 안드로이드 시스템 파일 탐색기/갤러리를 연동.
   * 다중 선택(`MODE_OPEN_MULTIPLE`) 및 `video/*`, `image/*` MIME 필터링 지원.
4. **Blob / Base64 GIF 네이티브 다운로드 엔진 (`WebAppInterface`)**:
   * 브라우저 기반 WebAssembly GIF 인코더(`gifenc`)가 생성하는 `blob:https://...` 다운로드를 네이티브 코드로 가로채어 Base64로 변환 후 시스템 다운로드(`Downloads/SmartGIF`) 폴더에 영구 저장.
   * Android 10+ Scoped Storage(MediaStore) 완벽 지원.
   * 다운로드 완료 시 네이티브 토스트 알림 및 클릭 시 바로 열 수 있는 시스템 푸시 알림 제공.
5. **뒤로가기 제스처 보호**:
   * 웹뷰 히스토리가 있으면 이전 페이지/상태로 이동하고, 첫 화면에서는 2초 내 연속 2회 누를 때만 안전하게 종료되도록 방지.

## 🚀 GitHub Actions로 APK 빌드하는 방법 (PC에 안드로이드 스튜디오 불필요)

사용하시는 컴퓨터에 안드로이드 스튜디오나 Java가 없어도, GitHub에 푸시하는 즉시 클라우드 가상 머신에서 APK를 빌드합니다.

### 1단계: GitHub에 코드 올리기

터미널(PowerShell 또는 Git Bash)에서 현재 프로젝트 폴더로 이동한 뒤 다음 명령어를 입력합니다:

```bash
# 1. git 저장소 초기화
git init

# 2. 모든 파일 스테이징 및 커밋
git add .
git commit -m "feat: 스마트 GIF 생성기 안드로이드 웹뷰 앱 및 빌드 워크플로우 구성"

# 3. 기본 브랜치 이름을 main으로 설정
git branch -M main

# 4. GitHub에서 새로 생성한 저장소 원격 연결 (본인 계정 URL 입력)
# 예시: git remote add origin https://github.com/<사용자명>/<저장소명>.git
git remote add origin <본인의-깃허브-저장소-URL>

# 5. GitHub에 푸시
git push -u origin main
```

---

### 2단계: GitHub Actions에서 자동 빌드 확인

1. 웹 브라우저로 본인의 GitHub 저장소 페이지에 접속합니다.
2. 상단 탭에서 **`Actions`** 를 클릭합니다.
3. `Build Smart GIF Android App` 워크플로우가 자동으로 실행 중인 것을 볼 수 있습니다. (약 2~3분 소요)
4. 만약 수동으로 다시 빌드하고 싶다면:
   * 좌측의 **`Build Smart GIF Android App`** 선택
   * 우측 상단의 **`Run workflow`** 버튼 클릭 -> `Run workflow` 초록색 버튼 클릭

---

### 3단계: 빌드된 APK 다운로드 및 폰에 설치

1. 완료된 워크플로우 실행 기록(녹색 체크 표시 ✅)을 클릭하여 상세 페이지로 들어갑니다.
2. 페이지 하단의 **`Artifacts`** 섹션을 확인합니다.
3. **`SmartGIF-Android-APKs`** 를 클릭하면 압축 파일(`zip`)이 다운로드됩니다.
4. 압축을 풀면 2개의 APK가 들어있습니다:
   * `SmartGIF-v1.0.0-debug.apk`: 디버그 서명 APK (모든 안드로이드 기기에 즉시 설치 가능)
   * `SmartGIF-v1.0.0-release.apk`: 최적화된 릴리즈 APK
5. 카카오톡, 구글 드라이브, 또는 USB 케이블을 통해 안드로이드 폰으로 APK 파일을 전송한 뒤 탭하여 설치합니다.
   *(최초 설치 시 "출처를 알 수 없는 앱 설치 허용" 팝업이 뜨면 '허용'을 선택하시면 됩니다.)*
